# projectINFS3203

projectINFS3203 is a web-based AI study assistant that allows users to save study notes and generate AI-powered summaries using Gemini.

## Features
- Save study notes
- View saved notes
- Generate AI summaries
- Simple web interface
- MongoDB storage

## AI Feature
The app uses Gemini to summarize study notes into short student-friendly bullet points.

## Tech Stack
- Flask
- MongoDB Atlas
- HTML/CSS
- Docker
- GitHub Actions
- Render
